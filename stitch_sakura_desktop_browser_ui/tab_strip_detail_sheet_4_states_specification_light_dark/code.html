Tab Strip Component Matrix & Four State Behaviors

Architectural reference detailing the 4 interaction states of the vertical tab strip: Revealed (240px), Pinned (240px docked), PinnedCollapsed (48px icons), and AutoHidden (4px hover sliver) across Light and Dark theme tokens.

Sliver/Accent: #F4A9C5 / #F7BBD4

Triggered via mouse hover on the 4px sliver or shortcut ⌘S. Floats above page content with elevation shadow 0 4px 16px rgba(0,0,0,.08). Auto-hides on cursor leave when unpinned.
